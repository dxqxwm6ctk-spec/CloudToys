# خطة دعم اللغتين (عربي / إنجليزي) لموقع Cloud Toys

**الحالة:** خطة مقترحة — لم يبدأ التنفيذ بعد.
**النطاق:** موقع المتجر (`artifacts/cloud-toys`) كأولوية. لوحة تحكم الأدمن (`artifacts/admin-dashboard`) اختيارية بمرحلة لاحقة لأنها أداة داخلية.

---

## 1. الهدف

يقدر الزائر يبدّل الموقع بين **العربية (RTL)** و **الإنجليزية (LTR)** من زر واحد ظاهر بكل الصفحات، مع:
- ترجمة كل نصوص الواجهة (أزرار، عناوين، رسائل).
- ترجمة محتوى المنتجات والفئات (الاسم، الوصف) لأن هذا محتوى يدخله الأدمن، مو كود.
- اتجاه الصفحة (RTL) يتبدّل تلقائيًا مع اللغة، مع تصحيح الأيقونات والتخطيطات المتأثرة بالاتجاه.
- اللغة المختارة تُحفظ (تفضيل المستخدم) وتُطبّق تلقائيًا بالزيارة القادمة.

---

## 2. القرارات التقنية المقترحة

| القرار | الخيار المقترح | السبب |
|---|---|---|
| مكتبة الترجمة | `i18next` + `react-i18next` | معيار قياسي بمشاريع React، يدعم fallback، namespaces، وسهل الدمج مع RTL |
| تخزين تفضيل اللغة | `localStorage` (بدون تغيير الرابط) | أبسط من إضافة بادئة مسار مثل `/ar/shop`؛ يحافظ على كل الروابط الحالية بدون كسرها |
| اتجاه الصفحة | `document.documentElement.dir` يتغيّر مع اللغة + تصميم Tailwind يعتمد خصائص منطقية (`ms-`, `me-`, `ps-`, `pe-`) بدل `ml-`/`mr-` بالمكوّنات المتأثرة | يتجنب الحاجة لنسخة CSS منفصلة لكل اتجاه |
| الخط العربي | إضافة خط عربي (مثل Cairo أو Tajawal من Google Fonts) يُستخدم تلقائيًا وقت `dir=rtl` | خطوط اللاتيني الحالية (serif/sans المستخدمة) ما تدعم العربي بشكل جيد |
| محتوى المنتجات/الفئات (اسم، وصف) | إضافة أعمدة موازية بقاعدة البيانات: `nameAr`, `descriptionAr`, `shortDescriptionAr` (وبالمثل للفئات) | المحتوى يُدخله الأدمن من لوحة التحكم، مو نص ثابت بالكود، فلازم يترجَم كبيانات لا كملفات ترجمة |
| نصوص الواجهة الثابتة | ملفات ترجمة JSON: `src/locales/en.json` و `src/locales/ar.json` | فصل النص عن الكود، يسهّل التعديل لاحقًا بدون لمس TSX |

## 3. التغييرات على قاعدة البيانات (Drizzle + Supabase)

- **`lib/db/src/schema/products.ts`**: إضافة أعمدة nullable:
  - `nameAr text`
  - `shortDescriptionAr text`
  - `descriptionAr text`
  - `featuresAr text[]` (اختياري إذا بدنا ترجمة الميزات)
- **`lib/db/src/schema/categories.ts`**: إضافة `nameAr text` (nullable).
- كل الأعمدة الجديدة **nullable** (لا `notNull`) — إذا ما تُرجم منتج معيّن، الموقع يرجع للإنجليزي تلقائيًا (fallback)، وما ينكسر شي بالبيانات الموجودة حاليًا.
- تنفيذ التغيير عبر `drizzle-kit push` على قاعدة Supabase (بيئة الإنتاج) — نفس الأسلوب المستخدم سابقًا بالمشروع. **يتطلب موافقة صريحة قبل التنفيذ لأنه تعديل مباشر على قاعدة بيانات الإنتاج.**

---

## 4. تغييرات الـ API (`artifacts/api-server`)

- إرجاع كل الحقول (الإنجليزي + العربي) بنفس الـ response بدل عمل endpoint منفصل لكل لغة — يخلي الواجهة تختار العرض المناسب فورًا بدون طلب إضافي عند تبديل اللغة.
  - مثال: `GET /api/products` يرجع `{ name, nameAr, description, descriptionAr, ... }`.
- تحديث `insertProductSchema` / `insertCategorySchema` (zod) ليقبلوا الحقول الجديدة كـ optional.
- إعادة توليد عميل الـ API (`lib/api-client-react`) عبر orval بعد تعديل الـ OpenAPI schema.

## 5. تغييرات لوحة تحكم الأدمن (`artifacts/admin-dashboard`)

- نموذج المنتج (`products/form.tsx`) والفئة (`categories/list.tsx` أو نموذج مشابه): إضافة حقول إدخال موازية للعربي (اسم عربي، وصف عربي…)، بشكل تبويب "English / عربي" أو حقلين متجاورين تحت كل حقل إنجليزي.
- لوحة الأدمن نفسها تبقى إنجليزية بالكامل بالمرحلة الأولى (أداة داخلية، مو أولوية).

## 6. تغييرات واجهة المتجر (`artifacts/cloud-toys`)

### 6.1 البنية التحتية
- تثبيت `i18next`, `react-i18next`.
- `src/i18n.ts`: إعداد i18next مع `en` كلغة افتراضية واحتياطية.
- `src/locales/en.json`, `src/locales/ar.json`: كل نصوص الواجهة الثابتة (الأزرار، العناوين، رسائل الأخطاء، إلخ) بدل النصوص المكتوبة مباشرة بالمكوّنات.
- `LanguageContext` (أو الاعتماد مباشرة على `i18next` + hook `useLanguage`) يدير: اللغة الحالية، `document.documentElement.dir` و `lang`، والحفظ بـ `localStorage` — بنفس نمط `CartContext`/`WishlistContext` الموجود بالمشروع.

### 6.2 زر تبديل اللغة
- زر/قائمة صغيرة بالهيدر (`Header.tsx`) — "EN / عربي" — يبدّل اللغة فورًا بدون إعادة تحميل الصفحة.

### 6.3 استبدال النصوص الثابتة
مسح كل الصفحات والمكوّنات واستبدال النص الإنجليزي المكتوب مباشرة بمفاتيح ترجمة (`t('...')`)، أهمها:
- `Header.tsx`, `Footer.tsx` (روابط التنقل، الحقوق)
- `Home.tsx` (شريط الأصناف، عناوين الأقسام)
- `Shop.tsx`, `Categories.tsx`, `ProductDetail.tsx`
- `Cart.tsx`, `Checkout.tsx` (كل خطوات الدفع ورسائل الأخطاء)
- `Account.tsx`, `MyOrders.tsx`, `TrackOrder.tsx`
- `About.tsx`, `Contact.tsx`

### 6.4 عرض محتوى المنتجات/الفئات بلغتين
- عند اللغة العربية: عرض `nameAr` إن وُجد وإلا الرجوع لـ `name` (نفس الشي للوصف والفئات).
- دالة مساعدة صغيرة `getLocalizedField(item, 'name', lang)` تُستخدم بكل مكان يعرض اسم/وصف منتج أو فئة.

### 6.5 الاتجاه (RTL) والتصميم
- `dir="rtl"` تلقائيًا على `<html>` عند اختيار العربي.
- مراجعة أماكن استخدام `ml-`/`mr-`/`left-`/`right-` الثابتة بالمكوّنات المهمة بصريًا (الهيدر، القوائم المنسدلة، السلة، شريط التقدّم بصفحة الدفع) واستبدالها بخصائص منطقية أو بشرط اتجاه، خصوصًا:
  - القائمة الجانبية بالجوال (`Header.tsx` — تنزلق من جهة معيّنة).
  - الأيقونات الاتجاهية (`ChevronRight`, `ArrowRight`) — تحتاج قلب بصري بوضع RTL.
- الأرقام والعملة: استخدام `Intl.NumberFormat` مع اللغة الحالية بدل `'en-US'` مثبتة بكل مكان (`formatPrice` بكل من `Cart.tsx`, `Checkout.tsx`, `MyOrders.tsx`, `Account.tsx`).

### 6.6 الخط
- إضافة خط عربي بـ `index.css` (استيراد من Google Fonts) وربطه بـ `[dir="rtl"] body`.

## 7. مراحل التنفيذ المقترحة

1. **مرحلة 1 — البنية الأساسية:** تثبيت i18next، إعداد اللغة والاتجاه والحفظ، زر التبديل بالهيدر، ترجمة الهيدر والفوتر فقط للتأكد إن الآلية شغالة.
2. **مرحلة 2 — نصوص الواجهة:** ترجمة باقي الصفحات الثابتة (Home, Shop, Cart, Checkout, Account, About, Contact...).
3. **مرحلة 3 — بيانات المنتجات:** إضافة أعمدة عربية بقاعدة البيانات + تحديث الـ API + تحديث نموذج الأدمن لإدخال الترجمة + عرضها بالمتجر.
4. **مرحلة 4 (اختياري):** ترجمة لوحة تحكم الأدمن نفسها.

كل مرحلة قابلة للتسليم والاختبار لحالها قبل الانتقال للتالية.

---

## 8. نقاط تحتاج قرارك قبل البدء بالتنفيذ

- هل نبدأ بالمرحلة 1 والمرحلة 2 فقط أول شي (نصوص الواجهة)، وتأجيل ترجمة بيانات المنتجات (مرحلة 3) لاحقًا؟
- تعديل قاعدة بيانات الإنتاج (إضافة أعمدة عربية) يحتاج تشغيل `drizzle-kit push` على Supabase — هل توافق على تنفيذه وقت وصولنا للمرحلة 3؟
- هل لوحة تحكم الأدمن نفسها تبقى إنجليزية بالكامل، أو تبيها مترجمة كمان؟
